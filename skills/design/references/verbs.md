# Steering verbs: one named change per refine pass

Adapted from Impeccable's commands (Apache-2.0) and Emil Kowalski's animation skills (MIT). A refine pass applies one or two verbs the critic chose, across the whole page, and nothing else.

| Verb | Use when the critic says | What changes |
|---|---|---|
| `bolder` | Safe, forgettable, "looks like everything else" | Commit harder to the world: bigger scale contrast, one braver color or form decision, the Moment made larger and more central. Never add decoration to get there. |
| `quieter` | Busy, competing elements, too much motion | Remove effects and secondary motion, drop to one accent, more space, fewer type sizes. The Moment stays. |
| `distill` | Cluttered, generic sections, card soup | Cut sections/elements to the essential, merge, replace containers with spacing and alignment. Answer "what breaks if this is gone?" for each element. |
| `typeset` | Type looks default or wrong for the character | Change faces, scale, measure, leading, tracking; theme selection/numerals; balance headings. |
| `animate` | Static where motion would explain, or motion that pops/steps | Build the motion story: bridges between beats, scroll-scrubbed continuity, pinned scenes that keep moving, two layers, bookends. Follow `motion.md`. |
| `polish` | Good idea, visible defects | Fix contrast, alignment, spacing rhythm, states, focus, hit areas, phone layout, reduced-motion state, console errors. |
| `harden` | Breaks in some state | Empty/error/no-JS/no-WebGL/reduced-motion paths, long text, 1000-1100 px widths. |
| `reground` | Swapping in another subject's name would still fit | Pull more of the subject's real content and world into the structure itself; replace generic sections. |

Rules: one verb, maybe two, per pass. Keep what the critic called the best thing. After the pass, capture again; the critic decides the next verb.
